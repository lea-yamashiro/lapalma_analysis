# Analysis of HESS J0632+057 (or HD259440)! 

Hey guys so I made Git. This is the general structure: 

- \texttt{lapalma_analysis:} this is the main Git repository that you will clone. 
- \texttt{LaPalma_analysis_main:} made this folder called "LaPalma_analysis_main", where we can keep the main standardized code and notebooks to run analysis. Currently this is just the code I have already done, but can be cleaned up for further and future use
- \texttt{analysis_AM}, \texttt{analysis_JM}, and \texttt{analysis_LY} are each of our individual folders. You can copy whatever you want from the main folder into these folders to work on your own analysis separately and then push changes to Git. This way, we don't have to worry about conflicting versions but there's still a place for all of us to work on our individual code and analysis. Also, if there are changes that we make in our own folders that we decide are good for the standardized code, we can just replace them or add them to the main code, like if a new version of the normalization script is done, we can add it to main code as \texttt{normalize_spectrum_v2_3.py} or something.
